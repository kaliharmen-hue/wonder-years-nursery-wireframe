# The Wonder Years Day Nursery homepage wireframe

Responsive Astro wireframe for reviewing the proposed homepage structure and copy.

## Review site

Once GitHub Pages has deployed, the preview will be available at:

https://kaliharmen-hue.github.io/wonder-years-nursery-wireframe/

## Notes

- Image areas are deliberately shown as labelled placeholders.
- Navigation links for future inner pages are placeholders at this stage.
- Testimonials and final nursery photography still need to be supplied.
- The layout is responsive for desktop, tablet and mobile.
